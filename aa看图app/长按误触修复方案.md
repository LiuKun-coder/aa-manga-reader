# 漫画列表长按误触修复方案（最小改动版）

## 一、问题

快速下滑漫画列表后，手指点按屏幕刹车时，点按位置的漫画被误判为长按，弹出「重命名 / 删除」ActionSheet。

## 二、方案

将长按触发时间从 200ms 提高到 1000ms。快速点按刹车通常 < 1s，不再触发长按；正常长按需按住 1 秒。

## 三、改动位置

仅 [pages/index/index.vue](file:///d:/aa看图app/pages/index/index.vue) 一处：

L863：
```js
const LONG_PRESS_DELAY = 200
```
改为：
```js
const LONG_PRESS_DELAY = 1000
```

其他逻辑（`onItemTouchMove` 的 10px 取消、`onItemTouchEnd`、`onItemClick`、`onMangaLongPress`）均不变。

## 四、影响

### 正面

- 解决点按刹车误触（快速点按 < 1s 不触发）。
- 改动仅一个常量，零风险，不涉及任何滚动 / 阅读器 / 删除重命名流程逻辑。

### 负面（已知权衡，用户已接受）

1. **长按响应变慢**：从 200ms 变为 1000ms，每次重命名 / 删除需按住 1 秒。这与此前「200ms 改善响应速度」的优化方向相反，但用户本次明确选择。
2. **按住刹车仍可能误触**：若用户点按刹车时手指停留超过 1 秒（按死直到列表完全停稳），仍会触发长按。这是单纯加时间的固有局限，无法根除。
3. **长按震动反馈延后**：震动从 200ms 后触发变为 1000ms 后触发，手感会略迟。

## 五、验证清单

1. 快速下滑 → 点按刹车 → 不弹 ActionSheet。
2. 列表静止 → 长按漫画约 1 秒 → 震动 + 弹出 ActionSheet。
3. 单击漫画 → 正常进入阅读器（`longPressTriggered` 为 false，走 `openManga`）。
4. 长按后手指移动 > 10px → 不触发（原有 10px 取消逻辑仍生效）。
